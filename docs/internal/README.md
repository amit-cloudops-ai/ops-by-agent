# Maintainer Working Notes

This directory contains project-continuity and programme-maintenance material. It is still part of this public repository and must not contain secrets, private customer information or confidential AWS account data.

## New project conversations

Use [NEW-CHAT-START-HERE.md](../programme/NEW-CHAT-START-HERE.md) as the entry point for a new ChatGPT conversation. Use the [project handoff template](../programme/PROJECT-HANDOFF-TEMPLATE.md) inside each approved agent folder.

## Portfolio planning

The complete candidate portfolio is in [PROJECT-SCORECARD.md](../programme/PROJECT-SCORECARD.md). It is intentionally separate from the homepage's release section. It is not private; anyone can browse it.

## Maintenance rule

Do not create directories for future agents until that project is individually approved. Keep implementation status, test evidence, AWS resource state, decisions and next steps current.
