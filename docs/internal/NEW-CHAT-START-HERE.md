# New Chat: Start Here

This copy is retained in the maintainer working area for convenient access. The canonical project-start instructions are in [docs/programme/NEW-CHAT-START-HERE.md](../programme/NEW-CHAT-START-HERE.md).

The repository is the source of truth. Never assume that chat history is available in a new conversation.
