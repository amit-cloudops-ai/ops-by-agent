# Architecture Decision Records

Use Architecture Decision Records (ADRs) for decisions that materially affect architecture, security, operations, cost, dependencies or public interfaces.

## Format
Create sequential files such as `0001-record-agent-runtime-choice.md` with:
- Status: proposed, accepted, superseded or deprecated.
- Context: problem, constraints and alternatives.
- Decision: selected approach.
- Consequences: benefits, trade-offs, risks and operational cost.
- Validation: evidence or conditions for revisiting.

Keep decisions concise and link related project documentation. Do not record secrets or sensitive account details.
